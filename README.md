# Labs Video Coding 2026

Repositorio de prácticas y laboratorios de **Video Coding** correspondientes al curso 2026.

## Contenido

Aquí se recopilan los ejercicios, implementaciones, experimentos y resultados relacionados con la codificación y el procesamiento de vídeo.

## Objetivos

- Comprender los fundamentos de la codificación de vídeo.
- Implementar y analizar algoritmos y herramientas de compresión.
- Evaluar la calidad, el bitrate y el rendimiento de distintas soluciones.
- Documentar los procedimientos y resultados de cada laboratorio.

## Organización

Cada laboratorio puede incluir, según corresponda:

- Código fuente y scripts de ejecución.
- Datos de entrada o instrucciones para obtenerlos.
- Resultados experimentales.
- Una memoria o documentación con el análisis realizado.

Una estructura recomendada es:

```text
.
├── lab-01/
├── lab-02/
├── lab-03/
├── README.md
└── requirements.txt
```

## Requisitos

Los requisitos concretos se indicarán en cada laboratorio. De forma general, se recomienda disponer de:

- Git
- Python 3
- FFmpeg
- Las dependencias listadas en `requirements.txt`, cuando exista

Para instalar las dependencias de Python:

```bash
pip install -r requirements.txt
```

## Uso

Clona el repositorio y accede al laboratorio que quieras ejecutar:

```bash
git clone https://github.com/u232017/Labs-Video-Coding-2026.git
cd Labs-Video-Coding-2026
```

Consulta el README o las instrucciones incluidas dentro de cada carpeta para conocer los comandos de ejecución y los resultados esperados.

## Estado

Este repositorio se irá actualizando a medida que se completen los distintos laboratorios.
